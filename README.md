# 抽斎年譜 TEI ビジュアライザ（二次利用例）

[若手図書館員DH勉強会『抽斎年譜』TEI/XML](https://github.com/dhlibrarianstudygroup/tei_chuusainenpu_public)（CC BY 4.0）の **二次利用例** です。同じ TEI/XML を別の角度から可視化し、オープンデータが再利用される様子をそのまま示すことを目的にしています。

公式ビューワ（本文・画像・人物カード等）: <https://chusaiweb-murata.netlify.app/>

## 3 つのビュー

| ビュー | 内容 | 使う TEI 要素 |
|---|---|---|
| **人物ネットワーク** | 同じ年次に登場する人物どうしを結んだ共起グラフ | `listPerson/person`、本文 `persName/@corresp` |
| **人物登場タイムライン** | 主要人物が抽斎の生涯のどの年に登場するか | `div`（年次）、`head`（年齢）、`persName/@corresp` |
| **年譜⇔渋江抽斎 対訳** | 年譜と森鷗外『渋江抽斎』の対応箇所を4列（原文＋現代語訳）で対照 | `anchor`（`cnN_s/_e`）、aozora 側 `anchor/@corresp` |

各ビューには、データから動的に算出した「読み取れること（例）」と「読み取りの注意」を併記しています。対訳の現代語訳は **AI による下書き（要校閲）** です。

## 設計方針

- **静的サイト**。ブラウザ標準の `DOMParser` で TEI を直接読み込み、ビルド工程なしで動作します。
- **実行時の外部 CDN 依存なし**。可視化ライブラリ（d3 v7）は `vendor/` に同梱しています。
- データは `data/` に**改変せず**（aozora は別途修正 PR 済み）取り込み、出典を明記しています。

## ローカルで動かす

`fetch` を使うため、ファイルを直接開くのではなく簡易サーバ経由で開いてください。

```
cd tei-chusai-viz
python3 -m http.server 8000
```

→ ブラウザで <http://localhost:8000/>

## 公開（GitHub Pages）

リポジトリの Settings → Pages → Build and deployment で **Deploy from a branch** を選び、`main` / `(root)` を指定すれば公開されます（追加のワークフロー不要）。

## データに関する注記

本サイトは原データ（CC BY 4.0）を**改変せず**読み込み、表示側で補正・名寄せを行っています。複数エージェントによるレビューで確認された既知の課題と対応状況は次のとおりです。

**表示側で対応済み**
- **人物の表記ゆれ**：同一人物が別IDで分裂していた箇所（尾島定子／尾嶋定子／尾島定、山内五百子／山内五百、矢島玄碩／矢鳥玄碩、渋江恒善／恒善）を別名表で名寄せし、ノード数を実数（約59名）に補正。
- **未同定の参照**：listPerson 未登録の被参照（岩田百合）は灰色・破線で区別表示。
- **孤立した注記**：年次 div の外（body 直下）に置かれた `<note>` 内の人物参照（市野迷庵の没年など）を、直前の年次へ継承して取りこぼしを防止。
- **対訳の取りこぼし**：小説側に複数の対応区間がある記事をすべて取得（〔…〕で連結）。ゼロ詰め表記ゆれ（`cn03_02`⇔`cn03_2`）を吸収し、青空側アンカー不足の2件（cn03_02・cn11_02）も「年譜のみ」行として表示。

**原データ側の課題（上流での修正が望ましい・PR候補）**
- **和暦→西暦の `@when` 誤り**：文化8年=1810（正=1811）、天保8年=1836（正=1837、2件）、安政元年=1855（正=1854）など。同一西暦に複数の年次 div が畳み込まれ、その年の共起・タイムラインに影響します。
- **対訳アンカーの不整合**：`cn03_2/cn03_3` のゼロ詰め不一致、`cn11_02_e`・`cn03_02_e` など終了アンカーの欠落。
- **`@corresp` の `#` 欠落**（29件）。現状コードは吸収しており実害はありません。

これらは原データ（`tei_chuusainenpu_public`）への修正 PR として別途提案予定です。

**可視化の解釈上の限界**
- ネットワークの「共起」は**同じ年次に年譜へ登場**したという意味で、各年内は総当たりで結ぶため、記述の濃い年が機械的に多数のエッジを生みます（エッジの約9割は単年共起）。直接の交流・血縁・師弟を示すものではありません。
- タイムラインの点は「その年の記事で**言及された**」ことを示し、祖先の生年・子孫の没年など回顧的言及を含みます。本人の活動年とは限りません。
